## Glossary

- **Lightning Network:** a payment layer on top of bitcoin for fast, cheap payments.
- **sats:** satoshis, the smallest unit of bitcoin. 100 million sats make one bitcoin.
- **ecash / Fedimint:** Fedimint is open-source software for community-run bitcoin custody that issues private "ecash" tokens. Fedi builds an app on it.
- **Nostr:** an open protocol for decentralized social networking and messaging.
- **bitcoin++ (btc++):** a developer conference series held in a different city for each themed edition. Each one includes a hackathon.
- **BitDevs:** local meetups for technical bitcoin discussion. Atlanta has one.
